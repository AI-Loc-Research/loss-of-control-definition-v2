# Threat Model Review: barrett_2016 — S10

**Scenario text:**
> ASI is not deterred from acting unsafely. To deter is to persuade another agent to refrain from taking some action by convincing the agent that the action is not in their own interest. Even if an ASI has decisive strategic advantage and unsafe goals, it potentially could still be deterred from using its advantage to cause catastrophe. However, Bostrom (2014) argues that an ASI with decisive strategic advantage would be undeterrable.
